# Configuration records

`development.json` contains guarded repository defaults. Console execution,
deployment and validation flags remain disabled, and `allowed_modes` is empty.
Documentation cleanup does not change them.

Other files record particular model/layout, qualification or installation scopes.
In particular, `production-installation.json` is an installation observation,
not a live device-health query. The latest unresolved console session is described
in [current status](../docs/project-status.md).

The selected native performance binary used separately compiled application
policies and authenticated private identity/build receipts. A clean checkout's
original-BF16 preparation lock, a historical layout and a later quantized runtime
profile must not be combined as if they were one ready-to-launch configuration.
See [getting started](../docs/getting-started.md).
