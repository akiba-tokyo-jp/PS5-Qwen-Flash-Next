# Tools

This directory contains research tooling from multiple dated campaigns. It is
not a set of interchangeable commands for a generic public installation.
Read [getting started](../docs/getting-started.md) and
[current status](../docs/project-status.md) first.

| Group | Entry points / purpose |
| --- | --- |
| Original checkpoint | `qwen_flash_next.py`: metadata and explicit authenticated downloads |
| Engine source | `fetch_engine.py`: acquire the pinned engine archive |
| Engine libraries | `build.py`: cross-build with the selected driver and workspace |
| Interface demo | `build_preview.py`: synthetic preview plus application object checks |
| Original conversion | `prepare_model.py`, `convert_model.py`: authenticated preparation contracts |
| Result review | `analyze_*.py`, `review_*.py`: scope-specific offline interpretation |
| Experimental builders | `build_*.py`: particular source/profile/provider constructions |
| Native operations | `run_*.py`, publication/transfer/close/retirement tools: explicit operator scopes |

Some scripts embed historical local paths or require private prior receipts.
They are evidence/reproduction tools for their original case, not portable
quick-start commands. A tool name does not imply native qualification or adoption.

Never rerun a consumed native initializer, launch, close or cache-window binding.
The latest ordinary-close/restoration is unresolved. Existing continuation tools
preserve completed work; they do not authorize automatic execution.
