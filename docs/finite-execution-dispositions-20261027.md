## Implemented native dispatch components

| File / function | Concrete behavior |
| --- | --- |
| `ready_expert_execution.h::ReadyExpertExecution::run` | Connect the actual source coordinator to one-graph serial, split serial and split overlap. Require whole-expert readiness, joined readers, matching prior/plan/completed epochs and original-order final reduction |
| `ready_expert_wave.h::begin_serial_graph/complete_serial_graph` | Jointly pin both finished groups for one physical serial-control graph, with one genuine completion. Never manufacture two wave epochs from one returned graph |
| `ready_expert_native.cpp::ReadyExpertNativeGraphs::prepare` | Build the real GGML original-BF16/F32 graphs and retain each original-ordinal mask |
| `allocate_workspace` | Price the actual GGML planner before allocation, enforce a 16 MiB working-buffer scope and preserve the 1792 MiB aggregate ledger, 512 MiB Direct reserve, 256 MiB Flexible reserve and original operational predicate |
| `dispatch` | Compare the ready-wave mask with the actual graph's original ordinals before dispatch. Persist the phase, call actual `ggml_backend_graph_compute`, synchronize and require the supplied native driver checkpoint before publishing completion |
| `close_completed` | Free the workspace only after matching completed execution, retired wave/reduction, joined source, positive synchronization and driver checks. Failed/unknown work retains its owners |

The GPU producer uses a pure fresh memory predicate while the source coordinator
owns the mutable backpressure gate. This avoids introducing concurrent mutation
of the existing gate. All GPU operations remain on the sole original producer.
The owner classes cannot be copied. Caller contexts, all six strong bank leases,
source callbacks, graphs and buffers must survive any failed/unknown operation.
There is no implicit GPU free, I/O cancellation, retry, reset or CPU fallback.

These are default-off components. They have not been connected to a qualified
physical two-wave fixture entry or production model graph. No application SELF
was rebuilt/deployed, no driver/profile changed, and no real GPU work occurred.
